# PlasticWorld CRM – демо (собранный сайт)

Демонстрационная версия микро-CRM для пластических хирургов: витрина услуг, заявка с фото, канбан врача.

Здесь только собранные файлы сайта для GitHub Pages. **Все данные и фото хранятся в вашем браузере** и никуда не
отправляются: политика безопасности (Content-Security-Policy в `index.html`) запрещает странице обращаться к
другим адресам. Сбросить демо – кнопка «Сбросить демо-данные» на главной.
